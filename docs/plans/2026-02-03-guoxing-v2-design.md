## 3. 技術規格

### 3.1 前端技術
- **框架**：Vanilla JS + Alpine.js
- **樣式**：Tailwind CSS (CDN)
- **圖示**：Lucide Icons
- **字型**：Baloo 2 + Comic Neue

### 3.2 資料儲存
- **主要**：GitHub 倉庫 (JSON 檔案)
- **讀取**：GitHub Raw URL 或 GitHub Pages
- **進度**：LocalStorage（瀏覽器本地）

### 3.3 多媒體支援
| 類型 | 來源 | 處理方式 |
|------|------|---------|
| 圖片 | Google Drive / Imgur / GitHub | `<img>` 標籤 |
| 影片 | YouTube | iframe 嵌入 |
| 音檔 | Google Drive | `<audio>` 標籤 |
| 文字 | JSON | 直接渲染 + TTS 朗讀 |

## 6. 簡化 Markdown 匯入格式

### 6.1 格式規範

```markdown
# 單元：北港溪糯米橋
圖示：🌉
說明：全台灣僅存三座的糯米橋之一

## 投影片

### 第1頁
類型：圖片
網址：https://drive.google.com/xxx/bridge.jpg
內容：這是北港溪糯米橋，位於國姓鄉

### 第2頁
類型：youtube
網址：https://youtube.com/watch?v=xxxxx
內容：來看看糯米橋的歷史故事

### 第3頁
類型：音檔
網址：https://drive.google.com/xxx/guide.mp3
內容：聽聽導覽員介紹糯米橋的建造方式

### 第4頁
類型：文字
內容：糯米橋是用石頭、糯米、紅糖建造的
它已經超過80年歷史了！

## 題目

### 基礎

Q1: 這座橋是用什麼黏起來的？
- 強力膠
- 糯米紅糖 *
解析：古人用糯米加紅糖當黏著劑

Q2: 橋下有幾個洞？
- 2個
- 4個 *
解析：數數看，有4個拱門

### 進階

Q1: 糯米橋是什麼時期建造的？
- 清朝
- 日治時期 *
- 民國時期
解析：建於1940年日治時期

### 挑戰

Q1: 為什麼用拱形設計？
- 比較好看
- 可以分散重量更堅固 *
- 比較省材料
解析：拱形結構可以把重量分散到兩邊
```

### 6.2 格式說明

- `*` 標記正確答案
- `類型`：image / youtube / audio / text
- `網址`：外部連結
- 難度分區：基礎 / 進階 / 挑戰
