# 國姓鄉土教材 - UDL 互動學習 App 設計文件

**建立日期**：2026-02-03
**專案名稱**：國姓鄉時空探險隊
**目標對象**：資源班學生（低功能低成就）與一般生

---

## 1. 專案概述

### 1.1 教學目標
- 認識南投縣國姓鄉的人文、地理、產業特色
- 跨領域整合學習：國語、數學、社會、自然
- 符合 UDL（通用設計學習）三大原則

### 1.2 UDL 支援

| 原則 | 實作方式 |
|------|---------|
| 多元呈現 | 文字朗讀、圖片輔助、可調整字體大小與對比度 |
| 多元表達 | 點選、語音、鍵盤三種作答方式 |
| 多元參與 | 三級難度、徽章系統、進度追蹤 |

---

## 2. 技術架構

### 2.1 技術選型
- **架構**：單一 HTML 檔案（離線可用）
- **CSS 框架**：Tailwind CSS (CDN)
- **互動邏輯**：Alpine.js (CDN)
- **語音朗讀**：Web Speech API (SpeechSynthesis)
- **語音辨識**：Web Speech API (SpeechRecognition)
- **資料儲存**：LocalStorage

### 2.2 瀏覽器支援
- Chrome 90+ ✅
- Edge 90+ ✅
- Safari 14+ ✅（語音辨識有限）
- Firefox 90+ ⚠️（無語音辨識）

## 3. 視覺設計系統

### 3.1 設計風格：Claymorphism（黏土風）
- 柔軟 3D 感、圓潤邊角
- 厚邊框（3-4px）
- 雙層陰影（inner + outer shadow）
- 圓角 16-24px

### 3.2 色彩系統

```css
:root {
  --color-primary: #0D9488;      /* 青綠 - 品牌主色 */
  --color-secondary: #2DD4BF;    /* 淺青 - 進度/輔助 */
  --color-cta: #EA580C;          /* 活力橙 - 行動按鈕 */
  --color-background: #F0FDFA;   /* 淡青 - 背景 */
  --color-text: #134E4A;         /* 深青 - 主要文字 */

  /* 學科顏色 */
  --color-chinese: #EC4899;      /* 粉紅 - 國語 */
  --color-math: #3B82F6;         /* 藍色 - 數學 */
  --color-social: #F97316;       /* 橘色 - 社會 */
  --color-science: #22C55E;      /* 綠色 - 自然 */
}
```

### 3.3 字體系統

```css
/* Google Fonts Import */
@import url('https://fonts.googleapis.com/css2?family=Baloo+2:wght@400;500;600;700&family=Comic+Neue:wght@300;400;700&display=swap');

/* 字體設定 */

```

### 3.4 無障礙規範

| 項目 | 規範 |
|------|------|
| 觸控目標 | 最小 64×64px |
| 按鈕間距 | 最小 12px |
| 對比度 | WCAG AA（4.5:1） |
| 焦點指示 | `focus:ring-4 focus:ring-teal-400` |
| 動畫 | 尊重 `prefers-reduced-motion` |

## 5. 功能規格

### 5.1 語音朗讀
- 題目出現時自動朗讀
- 可點擊「再聽一次」重複朗讀
- 使用中文語音（zh-TW）
- 朗讀速度：0.8（較慢，適合學生）

### 5.2 語音辨識
- 點擊「說出答案」啟動
- 支援選項編號（「一」「二」「三」）
- 支援選項內容（「糯米紅糖」）
- 自動 5 秒超時

### 5.3 難度切換
- 三級難度：基礎 ⭐ / 進階 ⭐⭐ / 挑戰 ⭐⭐⭐
- 可在設定中切換
- 可在答題時即時切換

### 5.4 進度追蹤
- LocalStorage 儲存
- 記錄：完成的地點、各學科成績、獲得的徽章
- 支援重置進度

### 5.5 徽章系統
- 每個地點完成 4 學科後獲得徽章
- 全部完成獲得「國姓探險王」勳章
