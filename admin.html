使用說明

簡化 Markdown 格式說明

# 單元：[單元名稱] 圖示：[emoji] 說明：[單元說明] ## 投影片 ### 第1頁 類型：[text/image/youtube/audio] 標題：[投影片標題] 網址：[媒體網址，text類型不需要] 內容：[說明文字，可多行] ## 題目 ### 基礎 Q1: [題目文字] - [選項A] - [選項B] * ← 加 * 表示正確答案 - [選項C] 解析：[答案解析] ### 進階 ... ### 挑戰 ...

投影片類型

  • text：純文字說明
  • image：圖片 + 文字（需要「網址」）
  • youtube：YouTube 影片（需要「網址」）
  • audio：MP3 音檔（需要「網址」）

如何使用

  1. 用 AI（Claude、Gemini、Felo）產生上述格式的文字
  2. 貼到左邊的輸入區
  3. 確認右邊的預覽正確
  4. 點「下載 JSON 檔案」
  5. 將檔案放到 data/units/ 資料夾
  6. 更新 data/index.json 加入新單元
